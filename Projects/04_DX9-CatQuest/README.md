# Project Overview

## 목표

DirectX 9 기반 환경에서 3D 게임 클라이언트의 기본 동작 구조를 이해하고,
Rendering Pipeline과 Gameplay System을 직접 구현하는 것을 목표로 진행했습니다.

특히:

- 3D Rendering Pipeline
- Game Object 구조
- Component 기반 관리
- Collision 처리
- Character / Camera System
- Gameplay Logic

을 중심으로 게임 클라이언트 개발의 기본 구조를 경험했습니다.
