## Policy

이 저장소에 포함하지 않는 것:

- C++ / Unreal 소스 코드
- `.uproject`, `.sln`, `.vcxproj` 등 프로젝트 파일
- 원본 메시, 텍스처, 사운드, 맵 데이터
- 비공개 리소스 및 라이선스 제한 자산

공개하는 것:

- 시스템 설계 문서
- 렌더링 / 네트워크 / 게임플레이 설명
- 런타임 검증 및 Negative Test 기록
- 스크린샷, 영상, 다이어그램
