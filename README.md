# Development Journey

프로젝트는 게임 클라이언트 개발을 학습한 흐름에 따라 단계적으로 확장되었습니다.

```text
WinAPI Isaac
→ Game Loop · Input · Object Basics

MFC Crazy Arcade
→ Team Project · Map Tool

DX9 Cat Quest
→ 4-Person Team · 3D Gameplay

DX11 SpongeBob BFBB
→ Native C++ · Rendering · Client Architecture

Imitation Trigger
→ Unreal Engine · Multiplayer · GAS · ADS

Rite Seekers
→ Unreal Engine · GAS · Gameplay Framework · Combat System
```

초기에는 게임이 실행되고 Object가 갱신되는 기본 흐름부터 시작했습니다.

이후 팀 프로젝트와 DirectX 기반 3D Gameplay를 경험했고,  
DirectX11에서는 Rendering과 Client Architecture까지 범위를 넓혔습니다.

현재는 Unreal Engine과 GAS를 중심으로  
Gameplay System과 Runtime Flow를 더 깊게 다루고 있습니다.
