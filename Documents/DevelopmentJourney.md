# Development Journey

WinAPI / DX9 기반 학습 프로젝트에서 시작해, 커스텀 DX11 엔진과 Unreal GAS 전투 파이프라인까지 확장한 과정입니다.

## Path

1. WinAPI 2D 게임 루프와 입력/충돌 기초
2. MFC 기반 멀티플레이 아케이드 클론
3. DirectX 9 3D 렌더링과 카메라/모델 파이프라인
4. 커스텀 DirectX 11 엔진 (렌더링, 애니메이션, 에디터)
5. 네트워크 게임플레이 클라이언트
6. Unreal GAS 기반 전투 파이프라인

## What Changed

- 기능 구현 중심에서 **시스템 경계와 데이터 흐름** 중심으로 설계
- 에디터/디버그 오버레이를 런타임 검증 도구로 사용
- 성공 경로뿐 아니라 실패/예외 경로를 문서화

## Next

- 대표 3개 프로젝트의 Architecture / Evidence / Media 완성
